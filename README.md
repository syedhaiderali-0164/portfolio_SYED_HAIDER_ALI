## 🌟 Highlights & Features

- **Cyber-AI Aesthetics**: Dark-mode-first aesthetic with electric cyan, violet, and emerald accents.
- **Interactive Neural Network Canvas**: Custom HTML5 Canvas background with dynamic nodes reacting to mouse interaction.
- **Dynamic Typing Effect**: Rotates through key technical specializations in the hero header.
- **Dark / Light Theme Toggle**: Preserves user preference in `localStorage` across page reloads.
- **Project Filter System**: Instantly filter projects by category (`Computer Vision`, `NLP & Chatbots`, `ML & Data Analysis`, `Apps & Hardware`).
- **Interactive Timeline**: Highlights industry internships (DiveDeepAI) and specialized vocational AI training (NAVTTC).
- **Direct Contact & Copy Utilities**: One-click email and phone copying with toast notifications, direct WhatsApp chat link, and email composer form.
- **Responsive & Lightweight**: 100% vanilla HTML5, CSS3, and JavaScript — zero heavy build tools or framework bloat needed. Ready for instant GitHub Pages deployment.

## 🚀 How to Upload & Deploy to GitHub Pages

You can host this portfolio website **100% free forever** on GitHub Pages. Here are two easy options:

### Option A: As Your Primary User Site (`https://syedhaiderali-0164.github.io`) [Recommended]

1. Go to [GitHub](https://github.com/new) and create a **new public repository** named:
   ```text
   syedhaiderali-0164.github.io
   ```
   *(Important: replace with your exact GitHub username followed by `.github.io`)*

2. Open PowerShell or Command Prompt in this folder (`c:\Users\DELL\Desktop\SYED_HAIDER_`) and run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: AI/ML Developer Portfolio"
   git branch -M main
   git remote add origin https://github.com/syedhaiderali-0164/syedhaiderali-0164.github.io.git
   git push -u origin main
   ```

3. Your website will be live at:
   👉 **`https://syedhaiderali-0164.github.io/`**

---

### Option B: In a Dedicated Repository (e.g., `portfolio`)

1. Create a repository on GitHub named `portfolio` (or any name you prefer).
2. In PowerShell inside this directory, run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: AI/ML Developer Portfolio"
   git branch -M main
   git remote add origin https://github.com/syedhaiderali-0164/portfolio.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** → **Pages** (under "Code and automation" in the left sidebar).
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In 1–2 minutes, your site will be live at:
   👉 **`https://syedhaiderali-0164.github.io/portfolio/`**
